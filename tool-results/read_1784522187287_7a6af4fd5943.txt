   212→### Summary
   213→Fixed 13 issues (3 CRITICAL, 10 HIGH) in the Mosaic Kitchen Display System. The fixes address memory leaks, unhandled errors, redundant socket work, mutation of computed arrays, missing user feedback, and Vite boilerplate CSS limiting the KDS display.
   214→
   215→### Fix Details
   216→
   217→| # | Severity | Issue | Fix |
   218→|---|----------|-------|-----|
   219→| 1 | CRITICAL | Socket channel listener never removed on unmount, causing duplicate listeners on remount | Stored handler as `this.socketHandler` in data(); added `socket.off(this.kot_channel, this.socketHandler)` in `beforeUnmount()` |
   220→| 2 | CRITICAL | Masonry instance created without destroying previous, causing layout corruption | Added `if (this.masonry) { this.masonry.destroy(); this.masonry = null; }` at start of `masonryLoading()` |
   221→| 3 | CRITICAL | Window resize handler fires on every pixel, causing severe jank | Added `debounce()` utility; resize listener now uses 150ms debounced wrapper stored as `this._resizeHandler`; properly removed in `beforeUnmount()` |
   222→| 4 | HIGH | Socket setTimeout (1500ms cancelled-KOT check) not cleared on unmount | Stored timeout as `this._cancelTimeout`; added `clearTimeout` in `beforeUnmount()` |
   223→| 5 | HIGH | No disconnect handler on socket — silent failures | Added `socket.on('disconnect', ...)` in `mounted()` with user-facing status message |
   224→| 6 | HIGH | `connect_error` handler only logged, no user feedback | Moved handler from module-level `initializeSocket()` to `mounted()` where `this` is available; sets `this.statusMessage = "Connection error. Retrying..."` |
   225→| 7 | HIGH | `audio.play()` promise not caught (autoplay policy rejection) | Changed to `audio.play().catch(() => {})` |
   226→| 8 | HIGH | `JSON.parse()` on localStorage value without try/catch | Wrapped in try/catch, defaults `striked` to `false` on parse error |
   227→| 9 | HIGH | `targetTime.split(":")` throws on null/undefined | Added guard: `if (!targetTime || !targetTime.includes(":")) return '— : —'` |
   228→| 10 | HIGH | Vite boilerplate `#app { max-width: 1280px; ... }` limits KDS on 1920px+ screens | Replaced with `#app { width: 100%; min-height: 100vh; }` |
   229→| 11 | HIGH | `sortedKotItems` computed mutates original `kot_items` array via `.sort()` | Changed to `[...kot.kot_items].sort(...)` using spread to create a copy |
   230→| 12 | HIGH | Socket handler does redundant `unshift` + `masonryLoading` when full refresh is already needed | Restructured to if/else: full refresh path skips intermediate mutations; incremental path adds reactive properties (`isRotated`, `showDiv`, `timecolor`, `timeRemaining`) |
   231→| 13 | HIGH | Dead code removal | Removed: `// inject: []`, `const self = this` (replaced usage with `this`), empty `<div></div>` in template, empty `socket.on('connect', () => {})`, empty `setup() {}` and `computed: {}` in Header.vue, commented-out imports in Header.vue |
